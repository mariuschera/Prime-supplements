- `screenshots-d3-pro/`: capturi JPG ale mockup-ului Pro, fiecare pagină pe desktop și mobil.
- `lighthouse-before/`: rapoartele Lighthouse de referință (HTML + JSON), mobil și desktop, pentru homepage, colecție și produs.
